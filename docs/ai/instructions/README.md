# Instructions

Curated excerpts of the instructions and skills that shaped the agent's
behavior in this homework.

## What goes here

- Short excerpts of the global agent instructions (`CLAUDE.md`) that explain
  a behavior you can see in the conversations.
- Excerpts of skills used during the work (for example TDD, commit or
  review skills).
- Project-level instructions, if the repository adds its own.

**Never paste the whole global instructions file.** It contains rules for
other tools and projects that are not relevant here and may leak private
context. Apply [../SHARING.md](../SHARING.md) to every excerpt.

## Format of each file

Each excerpt file starts with:

```markdown
# <Short title>

- **Source:** <file or skill name, no absolute path>
- **Why it matters:** <one or two sentences linking it to this homework>

<the excerpt>
```

## Naming convention

`<source>-<topic>.md`, lowercase, hyphen-separated. Examples:

- `claude-md-odd-protocol.md`
- `claude-md-delegation-rules.md`
- `skill-work-unit-commits.md`
