# Specs

Planning artifacts for each change in this homework.

## SDD changes

When a change runs through SDD, its artifacts are produced under
`openspec/changes/<change>/` and mirrored here:

```
specs/<change>/
  proposal.md   # intent, scope, approach
  specs/        # requirements and scenarios (delta specs)
  design.md     # architecture decisions and trade-offs
  tasks.md      # ordered implementation checklist
```

## ODD features

Most work runs through ODD. Its feature documents live in
`odd/tasks/<feature>.md` (objective, scope, checklist, verification evidence,
commits). Link them here instead of copying them.
